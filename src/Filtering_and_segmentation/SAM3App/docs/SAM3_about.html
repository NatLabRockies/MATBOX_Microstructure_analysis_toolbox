SAM 3 Segmenter

Version 1.9 · MATLAB R2026b app for point-and-click segmentation of 2D images and 3D volumes (TIFF)
This app specifically (not SAM itself) has been designed by Francois Usseglio-Viretta with the help of Claude Opus 5.5 at the National Laboratory of the Rockies (NLR)

The app runs Meta's Segment Anything Model 3 (SAM 3, and experimentally SAM 3.1) from github.com/facebookresearch/sam3 in a local Python environment. You click inside an object to include it and outside to exclude, and SAM returns the mask. For volumes, the object can be propagated from one slice through the stack with SAM 3's memory-based tracker, treating the slices as video frames.

In your methods, it also helps to state the model (SAM 3 or SAM 3.1), the checkpoint (facebook/sam3, sam3.pt), whether masks were refined by hand (the number of clicks per object is saved in the .mat export), and for volumes, that 3D masks were obtained by propagating a single-slice prompt with SAM 3's tracker.
